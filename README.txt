HOW TO PUBLISH THE GROUP 3 WEBSITE (free, approved platform: GitHub Pages)

The site is a single file (index.html). Every chart and diagram is drawn in the code,
so there are no image files to add.

1. Go to github.com > New repository > name it e.g. bisy2004-a2-group3 > Public > Create.
2. Click "uploading an existing file", drag in index.html, then Commit.
3. Go to Settings > Pages > Source: "Deploy from a branch" > Branch: main, folder: / (root) > Save.
4. After about 1 minute your link appears: https://<your-username>.github.io/bisy2004-a2-group3/
5. Open the link in a private/incognito window to check the lecturer can see it without logging in.
6. Put the link in the evidence pack and on the submission page.
